# Запуск тестов

Запусти тесты проекта, определив тип проекта автоматически:
- Node.js: `npm test` или `yarn test`
- Python: `pytest -v` или `python -m pytest`
- Go: `go test ./...`
- Rust: `cargo test`

Если есть ошибки:
1. Покажи полный вывод
2. Проанализируй причины
3. Предложи исправления

Если тестов нет - спроси, нужно ли создать базовые тесты.
