# Code Review

Проанализируй последние изменения (uncommitted или последний коммит):

1. Запусти `git diff` или `git show HEAD`
2. Проверь:
   - **Качество кода**: читаемость, сложность, дублирование
   - **Потенциальные баги**: null checks, edge cases, race conditions
   - **Безопасность**: SQL injection, XSS, secrets в коде
   - **Производительность**: N+1, лишние циклы, блокирующие операции
   - **Стиль**: соответствие конвенциям проекта
3. Дай конкретные рекомендации с примерами кода

Будь конструктивен. Фокусируйся на важных проблемах, не придирайся к стилю если он консистентный.
