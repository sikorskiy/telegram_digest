# Новая фича

Реализуй новую фичу: $ARGUMENTS

## План работы:

### 1. Анализ (Research)
- Изучи существующую кодовую базу
- Найди где логично интегрировать фичу
- Проверь нет ли похожей функциональности

### 2. Дизайн (Design)
- Предложи архитектуру
- Опиши публичные API/интерфейсы
- Определи зависимости
- Не переусложняй! KISS principle

### 3. Реализация (Implementation)
- Основная логика
- Обработка ошибок (граничные случаи)
- Валидация входных данных
- Логирование для отладки

### 4. Тесты (Testing)
- Unit тесты для основных сценариев
- Edge cases
- Error handling

### 5. Документация (Documentation)
- Обнови README если нужно
- Добавь docstrings/комментарии для сложной логики
- Примеры использования

## Важно:
- Спрашивай о деталях, если требования неполные
- Следуй стилю существующего кода
- Не ломай существующие API без обсуждения
