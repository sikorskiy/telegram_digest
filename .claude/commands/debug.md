# Debugging Session

Помоги отладить проблему. Аргумент: описание ошибки или путь к файлу.

План действий:
1. Изучи стек ошибки / описание проблемы
2. Найди и прочитай релевантные файлы
3. Проанализируй flow выполнения
4. Проверь типичные причины:
   - Null/undefined/None значения
   - Неправильные типы данных
   - Race conditions
   - Off-by-one errors
   - Состояние (state) не синхронизировано
5. Предложи исправление с объяснением WHY

Если контекста недостаточно - задай уточняющие вопросы:
- Как воспроизвести?
- Что ожидалось?
- Какие данные на входе?
- Когда началось (после каких изменений)?
